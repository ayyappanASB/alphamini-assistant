# Contributing

Open an issue describing a proposed change or reproducible problem before substantial work. Include the operating system, Python version, relevant dependency versions, and robot firmware when available. Remove secrets and personal identifiers from logs.

Keep server and vision dependencies separate. Preserve the single SDK connection and shared command coordination. For a pull request, explain the behavior change and how it was checked; distinguish syntax checks, simulation, and actual hardware testing.

Do not commit virtual environments, generated bytecode, credentials, recordings, or local IDE settings. No open-source license has been selected; clarify reuse and contribution terms with the repository owner when needed.
